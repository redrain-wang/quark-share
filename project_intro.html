2单部影片处理流程

每条任务经历 7 个环节，任何环节失败都有对应的兜底策略，不重复转存、不浪费配额。

STEP 1

院线优先级排序

从 mac_vod 按上映日期提取当年院线电影，中国大陆 P300 > 海外 P200 > 其他 P100，最近上映排最前，游戏/体育/纪录片杂质降级 P10。

ORDER BY priority DESC, release_date DESC
STEP 2

多源搜索 + 相关性过滤

so.252035.xyz TG源 → so.easysvip.com → 本地Docker，逐级降级。剔除"头像合集"等不相关结果。

polling + fallback × 5 endpoints
STEP 3

API 转存

sharepage/token → detail → save → 轮询 task。提取码错误、链接失效、分享者封禁自动换下一条（最多5条）。转存后立即记录 fid。

quark_api.transfer_and_share(skip_share=True)
STEP 4

可信 UI 分享

CDP 接管真 Chrome，拟人鼠标轨迹（贝塞尔移动+抖动+按下延迟）完整驱动 UI：勾选文件 → 分享 → 创建分享 → 读弹窗短链。

browser_share.create_share_via_trusted_ui()
STEP 5

双库写入 + 实时同步

先写本地 mac_vod_netdisk（每个 vod_id 一行），再幂等直写线上库。线上同步失败由 sync_push.py 按游标补偿。

INSERT ... WHERE NOT EXISTS（幂等）
STEP 6

审计巡检自愈

每轮开始匿名访客视角验证全部已完成分享。被夸克内容审核下架的 → 清除线上死链 → 重置任务 → 可信UI补分享。

audit_and_reset_completed()

3踩坑记录：夸克风控攻防

本项目 80% 的难度在夸克的风控体系。以下是全部踩过的坑与最终解法。

风控手段现象错误定位最终解法
TLS 指纹 aiohttp 创建的分享全部被审计下架（401 加密挑战体） POST /share 返回 401，Body 为 AATFelIx... 加密串 分享环节改用 CDP 真 Chrome
合成事件检测 页面上下文 fetch、JS el.click() 创建的分享同样被下架 对比实验：真鼠标创建存活，程序创建全部死亡 Playwright page.mouse 可信事件 + 拟人轨迹
内容审计 分享创建成功但几小时内被下架，访客看到"文件已被分享者删除" 分享列表 audit_status=4 每轮匿名审计巡检 + 死链自动重置重分享
混淆文件名 分享者命名 南z京z照z相z馆、B-捕-FENG-追-YING，名称去重失效导致重复转存 网盘出现大量 (1)(2) 副本 转存时记录 fid + CJK 字符提取模糊匹配
无头浏览器检测 headless 模式下分享页 iframe 永远骨架屏 断点调试 iframe 内容加载 headless=False + 反检测脚本注入
Cookie 轮换 转存接口响应轮换 __puus，静态 Cookie 头渐渐失效 响应 Set-Cookie 监测 手动捕获 Set-Cookie 更新请求头
搜索噪音 PanSou 返回"头像合集"等无关内容被误转存 网盘出现垃圾文件夹 影片名 CJK 相关性过滤
链接时效 分享者封禁 / 取消分享 / 链接失效混杂 stoken 接口错误信息分类 逐条轮换，失效类型精确入库

⚔关键对照实验：什么创建方式能活？

同一账号、同一文件、同一时段的三组对照 —— 只有真实输入管线的事件存活。

❌ 被审计拦截的创建方式

  • aiohttp 裸 API（即使带全套浏览器指纹头）
  • CDP 页面上下文 fetch（真实 Chrome 会话）
  • JS el.click() 驱动 UI（isTrusted=false）
  • headless 浏览器任何操作

✅ 存活的创建方式

  • CDP 接管真 Chrome（isTrusted=true）
  • 拟人鼠标轨迹：分段移动 + 抖动 + 按下延迟
  • 完整 UI 流程：勾选 → 分享 → 创建分享
  • 弹窗读取 12 位短码链接（pwd_id）

4数据模型

本地与线上同构。任务表驱动全流程，映射表支持一部影片对应多个采集站 vod_id。

表位置职责关键字段
quark_transfer本地转存任务（每部影片一条）priority · release_date · quark_fid · my_url · status
quark_link_vod本地链接 ↔ vod_id 一对多映射transfer_id · vod_id
mac_vod_netdisk本地 + 线上网盘资源（网站读取的表）vod_id · type · share_url · pwd · quality
cloud_accounts本地网盘账号池（多账号扩展位）disk_type · phone · cookie · status

任务状态机：0 待处理 → 2 已转存 / 5 待补分享 → 3 已分享入库； 4 无资源（3次搜索无果）

6项目结构

cloud_save_service/
├── ├── batch_runner.py # 常驻运行器（探针 + 审计巡检 + 分轮调度）
├── task_flow.py # 单任务流程（搜索→转存→分享→入库）
├── quark_api.py # 夸克 REST API 客户端（stoken/转存/任务轮询）
├── browser_share.py # ★ 可信事件 UI 分享（核心突破）
├── pansou_client.py # 多端点搜索 + 降级 + 轮询
├── anti_detect.py # 反检测（随机延迟/每日上限/强制休息）
├── db.py # 数据库操作
├── sync_push.py # 本地→线上增量同步（游标断点续传）
├── reconcile.py # 分享对账（401 已创建但响应被拦的找回）
├── cleanup_dups.py # 网盘重复文件清理
├── db_watchdog.py # 数据库看门狗
├── extract_cookies.py # Chrome Cookie 提取
├── init_db.py # 建表脚本
├── config.py # 全部配置
├── db_online.ini # 线上库连接信息
├── db_online.ini # 线上库连接（gitignore，不入库）
├── reports/ # 每日转存报告（自动生成）
├── browser_data/ # Cookie 持久化
└── screenshots/ # 调试截图
